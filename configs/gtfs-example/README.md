# Example GTFS feed

Made-up stops and lines placed near the CNRPark+EXT car park so the demo can show the
"leave the car and ride" panel. They are not real services. For a real site, point
`SPARK_GTFS` at the operator's published GTFS folder (only `stops.txt` is required;
`routes.txt`, `trips.txt` and `stop_times.txt` add the lines serving each stop).
